
# Food Management System

## 1. Giới thiệu
Ứng dụng quản lý món ăn, hỗ trợ xem danh sách, tìm kiếm, thêm, cập nhật và xóa món ăn.

## 2. Công nghệ sử dụng
- Frontend: React
- Backend: Node.js, Express
- Database: MongoDB Atlas
- Container: Docker

## 3. Cấu trúc dự án
- `frontend/`: mã nguồn giao diện React.
- `backend/`: mã nguồn API.
- `.gitignore`: các tệp không đưa lên Git.
- `README.md`: tài liệu mô tả dự án.

## 4. Cài đặt và chạy
### Backend
Mở Terminal tại thư mục `backend/`:
```bash
npm install
```

Tạo file `.env` với các biến môi trường cần thiết trước khi khởi động backend.

### Frontend
Mã nguồn React sẽ được bổ sung trong thư mục `frontend/` ở bước tiếp theo.

## 5. Bảo mật
Không đưa file `.env`, mật khẩu, access token hoặc chuỗi kết nối cơ sở dữ liệu chứa thông tin xác thực lên GitHub.
